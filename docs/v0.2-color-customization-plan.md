# Fluency Bridge v0.2 – Özelleştirilebilir Vurgu Renkleri Geliştirme Planı

Bu doküman, Obsidian Fluency Bridge eklentisinde **çevrilen/düzenlenen kelimeler (`[...]`)** ile **cümledeki yazım hataları / nüans uyarıları (typo & nuance)** için kullanıcı tarafından ayarlanabilir renk seçimi özelliğinin mimarisini, git branch stratejisini ve uygulama adımlarını tanımlar.

---

## 1. Hedef ve Kapsam

### 1.1 Amaç
Kullanıcıların kendi Obsidian tema tercihlerine (açık/koyu tema, özel renk paletleri) ve kişisel görsel zevklerine göre:
1. **Düzenlenen / Çevrilen İfade Rengi (`fb-replaced`):** `[...]` bloğundan dönüştürülen metnin arka plan ve alt çizgi rengini seçebilmesi.
2. **Yazım Hatası & Nüans Rengi (`fb-nuance`):** Cümlede yapay zeka tarafından tespit edilen yazım hatası ve doğallık uyarılarının arka plan ve dalgalı alt çizgi rengini seçebilmesi.
3. **Canlı Önizleme & Anında Güncelleme:** Ayarlardan renk seçildiği anda editörü veya Obsidian'ı yeniden başlatmaya gerek kalmadan açık notlardaki tüm vurgu renklerinin anında değişmesi.
4. **Tek Tıkla Sıfırlama:** İstenildiğinde varsayılan optimize edilmiş renklere kolayca geri dönülebilmesi.

## 3. Mimari ve Teknik Tasarım

### 3.1 Veri Modeli (`src/types.ts`)
Eklenti ayarları (`FluencyBridgeSettings`) genişletilecek:

```typescript
export interface FluencyBridgeSettings {
  // ... mevcut ayarlar
  highlightStyle: HighlightStyle;
  highlightReplacedText: boolean;
  highlightFlaggedNuances: boolean;
  
  // v0.2 Renk Özelleştirme Alanları
  replacedHighlightColor: string; // Hex formatı: örn. "#3b82f6" (Mavi)
  nuanceHighlightColor: string;   // Hex formatı: örn. "#f59e0b" (Kehribar)
}

export const DEFAULT_SETTINGS: FluencyBridgeSettings = {
  // ... mevcut varsayılanlar
  highlightStyle: "decorations",
  highlightReplacedText: true,
  highlightFlaggedNuances: true,
  
  // Varsayılan Renkler
  replacedHighlightColor: "#3b82f6",
  nuanceHighlightColor: "#f59e0b",
};
```

### 3.2 Dinamik CSS Değişkenleri Altyapısı (`styles.css`)
Sabit renk tanımları yerine dinamik CSS Custom Properties (CSS Değişkenleri) kullanılacaktır:

```css
/* ==========================================================================
   v0.2 Dinamik Vurgu Stilleri (CSS Değişkenleri ile)
   ========================================================================== */

:root {
  --fb-replaced-color: #3b82f6;
  --fb-replaced-bg: rgba(59, 130, 246, 0.18);
  --fb-nuance-color: #f59e0b;
  --fb-nuance-bg: rgba(245, 158, 11, 0.18);
}

.fb-highlight {
  display: inline;
  border-radius: 4px;
  padding: 1px 5px;
  margin: 0 1px;
  cursor: help;
  transition: background-color 0.15s ease, border-color 0.15s ease;
  font-weight: inherit;
  color: inherit;
}

/* 1. Düzeltilen / Çevrilen İfade */
.fb-replaced {
  background-color: var(--fb-replaced-bg);
  border-bottom: 2px solid var(--fb-replaced-color);
}

/* 2. Cümle İçi Hata & Nüans Uyarısı */
.fb-nuance {
  background-color: var(--fb-nuance-bg);
  text-decoration: underline wavy var(--fb-nuance-color);
  text-underline-offset: 3px;
  border-bottom: none;
}

.fb-highlight:hover {
  filter: brightness(1.12);
}
```

### 3.3 Dinamik Stil Enjeksiyon Servisi (`src/main.ts` veya `src/services/colorManager.ts`)
Kullanıcının seçtiği Hex rengini (`#3b82f6`) hem kenarlık/alt çizgi rengi olarak hem de transparan arka plan rengi (`rgba(...)`) olarak DOM'a aktaran yardımcı mekanizma:

- **Hex to RGBA Dönüştürücü:** Hex kodunu 0.18 (açık tema) veya 0.24 (koyu tema) opaklık değerine dönüştürür.
- **Canlı Enjeksiyon:** `document.body.style.setProperty('--fb-replaced-color', hex)` ve `document.body.style.setProperty('--fb-replaced-bg', rgba)` çağrıları ile doğrudan Obsidian arayüzüne işlenir.
- **Tetiklenme Noktaları:**
  1. Eklenti ilk yüklendiğinde (`onload`).
  2. Ayarlar sekmesinde renk seçimi yapıldığında (`onChange`).
  3. Varsayılana sıfırlama butonuna basıldığında.
  4. Eklenti kapatıldığında (`onunload`) değişkenler temizlenir.

> **Neden Bu Yöntem?**  
> CodeMirror 6 StateField ve Decoration sınıfları `.fb-replaced` ve `.fb-nuance` sınıflarını kullanmaya devam eder. Editördeki mevcut DOM elementlerini yeniden oluşturmaya gerek kalmadan, sadece CSS değişkeni güncellendiğinde tüm açık notlardaki renkler anında ve performans kaybı olmaksızın değişir.

### 3.4 Ayarlar Kullanıcı Arayüzü (`src/settings.ts`)
Obsidian'ın yerel `addColorPicker` bileşeni kullanılarak sezgisel bir arayüz tasarlanacaktır:

1. **"Metin İçi Vurgulama & Renklendirme" Başlığı Altına:**
   - **Çevrilen İfade Rengi:**
     - Açıklama: `[...]` içerisinden çevrilen hedef ifadenin vurgu rengi.
     - `addColorPicker`: Renk seçici paleti.
     - `addButton`: "Varsayılana Sıfırla" butonu.
   - **Yazım Hatası ve Nüans Rengi:**
     - Açıklama: Cümledeki olası yazım hataları ve doğallık uyarılarının dalgalı çizgi rengi.
     - `addColorPicker`: Renk seçici paleti.
     - `addButton`: "Varsayılana Sıfırla" butonu.

## 5. Doğrulama ve Test Senaryoları

Aşağıdaki senaryolar geliştirme tamamlandıktan sonra test edilecektir:

1. **Renk Değiştirme (Canlı Yansıma):**
   - Ayarlardan çevrilen ifade rengi yeşil (`#10b981`), hata rengi kırmızı (`#ef4444`) yapılır.
   - Açık nottaki mevcut vurguların anında yeşil ve kırmızıya dönüştüğü gözlemlenir (yeniden başlatma gerekmez).
2. **Kalıcılık (Persistence):**
   - Obsidian kapatılıp yeniden açılır veya eklenti yeniden yüklenir (`Reload app without saving`).
   - Seçilen renklerin korunduğu doğrulanır (`data.json` içine kaydedilmiştir).
3. **Varsayılana Sıfırla:**
   - Sıfırla butonuna tıklandığında çevrilen ifade `#3b82f6` (mavi), nüans `#f59e0b` (kehribar) rengine geri döner.
4. **Tema Değişimi:**
   - Obsidian açık ve koyu tema arasında geçiş yapılırken renk kontrastının ve okunabilirliğin korunduğu teyit edilir.
5. **Yeni Çeviri Uygulama:**
   - Yeni bir `[kelime]` çevirisi ve yazım hatası olan cümle çalıştırılır (`Cmd + Shift + E`).
   - Yeni oluşan vurguların kullanıcının seçtiği renklerle oluştuğu doğrulanır.
